# Sommelier Profesional Método CruCo — experiencia web

Versión web del curso **Sommelier Profesional Método CruCo**, de CruCo. Wine Studio.
Es un sitio **estático**: no necesita servidor de aplicaciones, base de datos ni
configuración. Se publica con GitHub Pages desde la raíz de este repositorio.

Contenido actual (módulo introductorio, 30 pantallas):

| | Lección | Pantallas |
|---|---|---|
| | ¡Bienvenido! | 2 |
| 1.a | El rol del sommelier: del servicio a la estrategia | 9 |
| 1.b | Áreas de acción y campos de ejercicio | 9 |
| 1.c | Tu valor estratégico | 10 |

El progreso de quien lo ve se guarda en su propio navegador. Esta copia no reporta a
ningún LMS: para eso existe el paquete SCORM, que se genera aparte.

Generado con `10-Web/04-Build/build.py --web` desde el proyecto de producción.
